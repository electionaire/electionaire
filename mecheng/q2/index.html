Method

  1. Eigenvalues of the system matrix. Solve \(\det(A-\lambda I)=0\). A lone diagonal entry is an eigenvalue; a block \(\begin{pmatrix}p&q\\-q&p\end{pmatrix}\) gives \(\lambda=p\pm iq\).
  2. Stability of the ODE. Stable if every \(\operatorname{Re}\lambda\le 0\), asymptotically stable if every \(\operatorname{Re}\lambda\lt 0\), unstable if any \(\operatorname{Re}\lambda\gt 0\). The step size plays no role here.
  3. Scale by the step size. For each \(h\), form \(z=h\lambda\) for every eigenvalue.
  4. Stability of the scheme. Stable only if every \(z\) lies in the shaded region \(|R(z)|\le 1\). One point outside is enough for instability.
  5. Read the figure's landmarks. RK3 reaches \(-2.51\) on the real axis and \(\pm1.73\) on the imaginary axis; RK4 reaches \(-2.79\) and \(\pm2.83\).
Amplification factors: forward Euler \(1+z\), backward Euler \(\frac{1}{1-z}\), trapezoidal \(\frac{1+z/2}{1-z/2}\), RK4 \(1+z+\frac{z^2}{2}+\frac{z^3}{6}+\frac{z^4}{24}\).
Trap. A purely imaginary pair such as \(\pm 2i\) makes the ODE stable but not asymptotically stable. The exam still calls it stable.
