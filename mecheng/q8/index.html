Method

  1. Look at the unknown. A scalar field \(u(\vec x)\) or \(T(\vec x)\) means a scalar problem with one degree of freedom per node. A vector field \(\vec u(\vec x)\) means a vector problem with one degree of freedom per node per direction.
  2. The weight function matches the unknown: \(\phi\) for scalar problems, \(\vec\phi\) for vector problems.
  3. Write each term in index notation. Every term must have the same free indices, and each index must pair with the same partner on both sides. Equal tensor order is not enough.
  4. The product rule has no normal vector. \(\vec n\) only appears after the divergence theorem: \(\int_V\vec\nabla\cdot(\ldots)\,dV=\int_S\vec n\cdot(\ldots)\,dS\).
  5. Reading code: u = zeros(n,1) holds plain numbers: a scalar degree-of-freedom column, so a scalar problem.
Vector rule (\(\boldsymbol\sigma\) symmetric): \(\vec\nabla\cdot(\boldsymbol\sigma\cdot\vec\phi)=\vec\phi\cdot(\vec\nabla\cdot\boldsymbol\sigma)+\vec\nabla\vec\phi^{T}:\boldsymbol\sigma\). Scalar rule: \(\vec\nabla\cdot(\phi\,\vec q)=\phi\,\vec\nabla\cdot\vec q+\vec\nabla\phi\cdot\vec q\).

Index notation used here: \(\vec\nabla\cdot\vec a=\partial_i a_i\), \((\boldsymbol A\cdot\vec b)_i=A_{ij}b_j\), \(\boldsymbol A:\boldsymbol B=A_{ij}B_{ji}\), \((\vec\nabla\vec\phi)_{ij}=\partial_i\phi_j\).
