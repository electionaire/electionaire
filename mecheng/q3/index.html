Method

  1. Find the update line inside the time loop. It decides the answer; the rest is setup.
  2. Explicit or implicit? If \(u_{n+1}\) comes from multiplying known values, such as uh(:,n)+h*A*uh(:,n), the scheme is explicit. If it needs a linear solve with \ on a matrix containing \(h\), such as (I-h*A)\uh(:,n), it is implicit.
  3. Rewrite as a difference quotient. \(\frac{u_{n+1}-u_n}{h}=A\,u_n\) is forward Euler; \(\frac{u_{n+1}-u_n}{h}=A\,u_{n+1}\) is backward Euler. The right-hand side is the \(f(u)\) of \(\frac{du}{dt}=f(u)\).
  4. Read the initial condition. uh(:,1) is the value at \(t_0=0\), because Matlab counts from 1. th = h*(0:N) with \(T=Nh\) gives the interval \((0,T)\).
  5. Reject the look-alikes. \(\frac{du}{dt}=u+Au\) would need I+h*(I+A); \(u(1)\) as initial condition would need the time grid to start at 1.
Implicit schemes cost a solve per step but stay stable for large \(h\) on decaying problems. Set \(N=10\) in the lab and compare forward and backward Euler.
